AtlasQueue: mantenimiento del índice

La versión del índice identifica el analizador y el corpus utilizado. Cambiar el analizador exige evaluar de nuevo las consultas.

Las reconstrucciones se hacen sobre un índice nuevo. El cambio de referencia ocurre después de comprobar que conserva los documentos esperados.

El identificador del documento es estable; la versión cambia cuando cambia el contenido. Dos versiones diferentes no deben compartir una cita sin especificar la revisión.

Una consulta sin resultados es válida. El sistema no debe inventar una respuesta para completar el top tres.
